# Drive scene replays (2D, top-down)

Real driving scenes from NAVSIM (OpenScene test logs, nuPlan maps v1.0), exported for a canvas replay.
Generated by a scratch script in jev-drive (`tmp/drive_web/export_scenes.py`, run with the navsim2 env on the GPU box).

The navhard ids match the `public/video/drive/navhard-*` clips. The JSON holds the **real logged** drive around the
original scene behind each navhard (synthetic stage-two) token, not the synthetic re-render.

## Conventions

- Coordinates: local frame, origin = ego pose at frame 0, **x forward, y left**, metres. Headings in radians,
  counter-clockwise from +x, wrapped to [-pi, pi). To draw with canvas y-down, flip y (and negate headings).
- Agent positions are box centres. Ego poses are the logged **rear-axle** pose (nuPlan convention); draw the ego box
  centred 1.46 m ahead along its heading.
- Time: `fps` = 2 (`dt` = 0.5 s). OpenScene logs are 2 Hz; interpolate positions and headings (shortest angle)
  for smooth playback. Each scene has 33 frames = 16 s (4 s before the planning frame, 12 s after).
- Numbers are rounded to 0.01 m / 0.001 rad. Polylines are simplified with Douglas-Peucker (0.3 m).

## Schema

```jsonc
{
  "version": 1,
  "fps": 2, "dt": 0.5,
  "frame": "local: origin = ego pose at frame 0, x forward, y left, metres, radians CCW",
  "current_frame": 8,                 // the NAVSIM planning frame inside the window
  "ego_size": { "length": 5.18, "width": 2.30 },   // nuPlan Chrysler Pacifica
  "ego": [[x, y, heading], ...],      // one per frame
  "agents": [                         // sorted vehicle, bicycle, pedestrian
    { "type": "vehicle" | "bicycle" | "pedestrian",
      "length": 4.6, "width": 1.9,    // median box size over the track
      "track": [[x, y, heading] | null, ...] }   // one per frame, null = not observed
  ],
  "traffic_lights": [                 // one list per frame
    [[connector_id, is_red (1|0)], ...]          // ids refer to map.connector_centerlines[].id
  ],
  "map": {                            // everything within 80 m of the ego path
    "drivable":   [[exterior, hole, ...], ...],  // polygons: rings of [x, y], first ring = outline
    "road_edges": [[[x, y], ...], ...],          // polylines: outline of the drivable area
    "lane_centerlines":      [[[x, y], ...], ...],
    "lane_boundaries":       [[[x, y], ...], ...],   // painted lane lines (deduplicated, lanes only)
    "connector_centerlines": [{ "id": 12345, "pts": [[x, y], ...] }, ...],  // lane paths through intersections
    "intersections": [[exterior, ...], ...],
    "crosswalks":    [[exterior, ...], ...],
    "walkways":      [[exterior, ...], ...],
    "stop_lines":    [[exterior, ...], ...]
  },
  "meta": {
    "id": "navhard-collision", "source": "...",
    "navhard_token": "1cdb5f8486a6e3a2b" | null, "original_initial_token": "2e1d4bde0a16514b",
    "scene_token": "...", "log_name": "...", "map_name": "us-nv-las-vegas-strip",
    "location": "Las Vegas Strip, NV, USA", "command": "left" | "straight" | "right" | "unknown",
    "start_timestamp_us": 0, "origin_global": [x_utm, y_utm, heading], "n_frames": 33, "duration_s": 16.0
  }
}
```

Agents are vehicles, bicycles and pedestrians that are observed in at least two frames and come within 60 m of the
ego path. Static objects (cones, barriers, signs, generic objects) are not exported. Some layers are empty in some
scenes (e.g. no crosswalks in `navhard-collision`, no agents in `navhard-stopped-slow`).
